## Local Development

```bash
# 1. Install dependencies
npm install

# 2. Start local development server (http://localhost:3000)
npm run dev

# 3. Type-check & lint
npm run typecheck
npm run lint

# 4. Production build
npm run build
npm run start
```

---

## Deploying to GitHub & Vercel

1. Upload this repository to GitHub (all source code in `src/`, media assets in `public/`, and configuration files are included).
2. Import the GitHub repository on [Vercel](https://vercel.com/new) — Vercel will automatically detect Next.js and deploy your live website in under 2 minutes.
